WWFC Database Backups

WWFC Database Backups is a private backup utility used to protect Woy Woy Football Club's Player Development Hub database.

How it works

The utility creates database backups, encrypts them locally using Rclone, and stores encrypted copies in an authorised Google Drive account.

The Google Drive connection is used to upload and retrieve backup files for recovery purposes. It is not a public file-sharing service.

Privacy and security

Database backup contents are encrypted before being uploaded to Google Drive. Encryption credentials are managed separately from this public website.
