Privacy Policy

Last updated: 11 November 2026

About this application

WWFC Database Backups is an internal backup utility used by Woy Woy Football Club to protect information stored in its Player Development Hub database.

Google Drive access

The application uses Google Drive API access to upload, retrieve and manage backup files created by the application.

Google Drive access is authorised by the account holder using Google's authentication process. The connection is used only for database backup storage and recovery.

Information stored

Database backups may contain personal information held within the Player Development Hub. Backup files are encrypted locally using Rclone before being uploaded to Google Drive.

Data security

Encryption credentials are maintained separately from the encrypted files. Google authentication credentials are stored locally for the operation of the backup utility.

Data sharing

The application does not sell Google user data or use it for advertising. Google Drive is used as a storage provider for encrypted backups.

Data retention

Local backups are subject to a 30-day retention process. Encrypted cloud backups are retained for recovery purposes and may be deleted by authorised administrators.

Revoking access

The Google account holder can revoke the application's Google Drive access through their Google Account security settings.
